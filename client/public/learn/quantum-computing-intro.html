A primer

An Introduction to Quantum Computing

Qubits, gates, and circuits — from first principles, with worked examples.

A classical computer manipulates bits, each definitely 0 or 1. A quantum computer manipulates qubits, which can exist in a blend of 0 and 1 at once and become correlated in ways no classical system can reproduce. This primer builds the core ideas in order — what a qubit is, the full vocabulary of quantum gates, and a gallery of small circuits that show those gates in action.

1The qubit

A single qubit’s state is written in Dirac (bra–ket) notation as a combination of the two basis states |0⟩ and |1⟩:

|ψ⟩ = α |0⟩ + β |1⟩

α and β are complex amplitudes. They are not probabilities directly — their squared magnitudes give the probability of each outcome when you measure:

P(0) = |α|², P(1) = |β|², with |α|² + |β|² = 1

A bit has two possible values; a qubit has a continuum of states (all valid α, β), yet a single measurement still yields just one classical bit. The constraint that probabilities sum to 1 means the state is a unit-length vector.

Key idea. Superposition is not “the qubit is secretly 0 or 1 and we don’t know which.” The amplitudes are physically real and can interfere — add and cancel — which is exactly what quantum algorithms exploit.

2Picturing a qubit: the Bloch sphere

A pure single-qubit state has two complex amplitudes constrained to unit length, with an irrelevant overall phase — so it maps to a point on the surface of a sphere, the Bloch sphere. The north pole is |0⟩, the south pole is |1⟩, and equal superpositions live on the equator.

3Single-qubit gates

A gate is a reversible operation — formally a unitary matrix. Single-qubit gates are 2×2 matrices, and each corresponds to a rotation of the Bloch sphere.

The Pauli gates

GateMatrixWhat it does
I — identity[ 1  0 ;  0  1 ]Does nothing (a “wait”).
X — bit flip (NOT)[ 0  1 ;  1  0 ]Swaps |0⟩ ↔ |1⟩. A 180° turn about the X axis.
Y[ 0 −i ;  i   0 ]Bit flip and phase flip. A 180° turn about Y.
Z — phase flip[ 1   0 ;  0 −1 ]Leaves |0⟩, negates |1⟩. A 180° turn about Z.

Superposition and phase gates

GateMatrixWhat it does
H — Hadamard(1/√2) [ 1   1 ;  1 −1 ]Creates an equal superposition: |0⟩ → |+⟩, |1⟩ → |−⟩. Maps the Z axis to the X axis.
S — phase (√Z)[ 1  0 ;  0  i ]A 90° phase on |1⟩ (quarter turn about Z).
S†[ 1   0 ;  0 −i ]The inverse of S (−90° phase).
T — π/8 (√S)[ 1  0 ;  0  eiπ/4 ]A 45° phase on |1⟩. With H, the set {H, T} is universal.
T†[ 1  0 ;  0  e−iπ/4 ]The inverse of T.
P(λ) — phase[ 1  0 ;  0  eiλ ]A tunable phase by angle λ on |1⟩. Z, S, T are P(π), P(π/2), P(π/4).

Continuous rotations

For arbitrary angles, the rotation gates turn the Bloch vector by θ about a chosen axis. They are the building blocks of variational and hardware-native circuits.

GateMatrixWhat it does
Rx(θ)[ cos(θ/2) −i sin(θ/2) ;  −i sin(θ/2)  cos(θ/2) ]Rotate θ about the X axis.
Ry(θ)[ cos(θ/2) −sin(θ/2) ;  sin(θ/2)  cos(θ/2) ]Rotate θ about Y (keeps amplitudes real — handy for real-valued states).
Rz(θ)[ e−iθ/2  0 ;  0  eiθ/2 ]Rotate θ about Z (a relative phase).
Universality. Any single-qubit gate can be built from rotations, and any quantum computation can be approximated to arbitrary accuracy with just H, T, and CNOT. That tiny set is enough to express everything.

4Multi-qubit gates

Single-qubit gates never create correlations between qubits. For that you need gates that act on two or more qubits at once — typically a controlled operation, where one qubit conditions an action on another.

GateQubitsWhat it does
CNOT / CX2Applies X to the target only when the control is |1⟩. The fundamental entangling gate.
CZ2Applies a phase flip (Z) to the target when the control is |1⟩. Symmetric — control and target are interchangeable.
CP(λ) / controlled-S, -T2A controlled phase by λ. The core ingredient of the Quantum Fourier Transform.
SWAP2Exchanges the states of two qubits. Equals three CNOTs back-to-back.
iSWAP2Swaps and adds an i phase — a common hardware-native two-qubit gate.
Toffoli / CCX3Flips the target only when both controls are |1⟩ — a reversible AND. Key to arithmetic and error correction.
Fredkin / CSWAP3Swaps two targets when the control is |1⟩. Used in the SWAP test.

6A gallery of circuits

Each example below is a complete, runnable circuit. Together they exercise every gate above.

A · Make a superposition

One Hadamard turns a definite bit into a 50/50 coin.

Result: |+⟩ = (|0⟩ + |1⟩)/√2. Measuring gives 0 or 1 with equal probability. Apply a second H and the two paths interfere — you return to |0⟩ exactly, not a random bit.

B · Interference: H · Z · H = X

A phase flip sandwiched between Hadamards becomes a bit flip — pure interference.

The Z gate flips the sign of |−⟩. Conjugated by Hadamards, that sign-flip on the X axis acts as a flip on the Z axis: the whole circuit equals a single X. (Likewise H·X·H = Z.) This identity is the simplest demonstration that phase and amplitude are two views of the same thing.

C · Bell state — two-qubit entanglement

Hadamard then CNOT: the canonical entangling circuit.

Result: |Φ⁺⟩ = (|00⟩ + |11⟩)/√2. The qubits are entangled — always measured equal (both 0 or both 1), though each alone is random. There is no way to describe either qubit on its own.

D · GHZ state — three-way entanglement

Extend the Bell idea with a CNOT chain.

Result: |GHZ⟩ = (|000⟩ + |111⟩)/√2. All three qubits flip together. GHZ states are maximally entangled and central to tests of quantum non-locality and to error-correction codes.

E · SWAP — exchange two qubits (= three CNOTs)

A SWAP can be built from three alternating CNOTs.

The two qubits end up exchanged. SWAP matters on real hardware, where qubits that aren’t physically adjacent must be shuttled next to each other before a two-qubit gate can act — the job of a router.

F · Toffoli — a reversible AND

Flip the target only when both controls are 1.

With target t starting in |0⟩, it ends as t = a AND b — computed reversibly, with the inputs preserved. Toffoli gates make classical logic (and thus arithmetic) expressible inside a quantum circuit, and they appear throughout quantum error correction.

G · Quantum teleportation

Move an unknown state from q₀ to q₂ using entanglement + 2 classical bits.

q₁ and q₂ start as a Bell pair. The sender entangles the unknown state q₀ with q₁, measures both (a Bell measurement), and sends the two classical outcome bits to the receiver, who applies a conditional X and/or Z to q₂ — which now holds the exact original state |ψ⟩. Nothing faster-than-light happens: the classical bits must travel, and q₀’s state is destroyed in the process (the no-cloning theorem is respected).

H · Grover search (2 qubits, one iteration)

Amplify the marked answer |11⟩ so a single measurement finds it.

Start in a uniform superposition (the two H gates). The oracle flips the phase of the marked state (here a CZ marks |11⟩); the diffusion operator then reflects all amplitudes about their average, converting that hidden phase into amplitude. For two qubits one round is enough — measuring yields |11⟩ with certainty. For N items Grover needs only ≈√N rounds, a quadratic speed-up over checking them one by one.

I · Quantum Fourier Transform (2 qubits)

The quantum analogue of the discrete Fourier transform — the engine inside Shor’s algorithm and phase estimation.

Each qubit gets a Hadamard, then controlled phase rotations (here a controlled-S) imprint the relative phases that encode frequency, and a final SWAP reverses the qubit order. On n qubits the QFT needs only ≈n²/2 gates to transform a 2ⁿ-dimensional state — exponentially fewer operations than the classical FFT touches numbers, which is what gives Shor’s algorithm its power.

7Measurement

Measurement is where the quantum world meets ordinary data. Measuring a qubit in the standard basis returns 0 or 1, with probabilities set by the squared amplitudes — and it collapses the state to the matching basis state. You don’t read out α and β; you get one sampled bit. So you run a circuit many times (“shots”) and study the statistics. You can also measure in a different basis by applying a gate first: an H before measurement reads the qubit along the X axis (the |+⟩/|−⟩ distinction), which is how many algorithms extract phase information.

8Why it matters

Superposition, interference, and entanglement together let certain problems be solved with far fewer steps than any known classical method:

  • Shor’s algorithm — factors large integers exponentially faster than the best classical methods, threatening today’s public-key cryptography. (It runs on the QFT from example I.)
  • Grover’s algorithm — searches N unstructured items in ≈√N steps (example H).
  • Quantum simulation — models molecules and materials whose quantum behaviour is intractable classically: chemistry, batteries, drug design.

The catch is noise. Real qubits decohere — they lose their delicate amplitudes to the environment in microseconds — and gates are imperfect. Today’s “NISQ” (noisy intermediate-scale quantum) devices have tens to a few hundred qubits with meaningful error rates. Turning them into reliable computers requires quantum error correction, which spreads one logical qubit across many physical ones using circuits built largely from the CNOT and Toffoli gates above — the central engineering challenge of the field.

A short glossary

QubitThe quantum unit of information; a superposition of |0⟩ and |1⟩.
SuperpositionA weighted combination of basis states existing simultaneously.
AmplitudeThe complex weight of a basis state; its squared magnitude is a probability.
InterferenceAmplitudes adding or cancelling — the source of quantum advantage.
EntanglementCorrelation between qubits with no independent description of each.
GateA reversible (unitary) operation transforming a state.
ControlA qubit that conditions a gate on another qubit (the filled dot).
Universal setA handful of gates (e.g. H, T, CNOT) that can build any computation.
MeasurementSampling a classical bit from the state and collapsing it.
DecoherenceLoss of quantum information to the environment (noise).
